# Static packet structure — physical PS2, 2026-09-22

This capture prices the static pipeline's command language before attempting
another packet rewrite. It used an isolated release-profile Motor District
fixture generated by `benchmark-district.py`, four frozen 240-frame poses and
the opt-in `TYRA_FRAME_PROFILE` stream walker. Every accepted row reported
`bad=0`.

`physical-summary.csv` contains per-frame medians. The garage submits roughly
197–213 VU1 packages/XGKICKs and 765–826 A+D state writes per frame. Terrain,
roads and static batches dominate the package count; the night delta is much
smaller than the total night frame-time increase, so packet count is not the
whole lighting bill.

## Rejected 128-byte REF alignment arm

An allocator-only arm aligned the base of each static `BagArray` to 128 bytes.
It preserved rendered geometry and package counts, but the 75-vertex package
stride is 1,200 bytes (48 modulo 128), so most later REF slices immediately
lost the alignment again. Garage-day aligned REFs moved only from 102/666
(15.3%) to 124/666 (18.6%). Physical frame work regressed:

| pose | ordinary | aligned | delta |
|---|---:|---:|---:|
| garage day | 30.35 ms | 30.53 ms | +0.18 ms |
| garage night | 52.04 ms | 52.13 ms | +0.09 ms |
| outer-road night | 35.15 ms | 35.20 ms | +0.05 ms |

The allocator change was therefore reverted. Revisit alignment only as part of
a package-baked representation that controls every slice start; padding the
source-array base alone does not survive the package stride.

## Consequences for the remaining article ideas

- VIF V2/V3 synthesis needs offline, per-package packed streams and padding;
  runtime repacking would move work onto the already busy EE.
- State differencing has a real theoretical target, but must first pass the
  minimal hardware packet harness: a previous REGLIST compaction rendered in
  PCSX2 and stalled the physical console.
- A multi-object VU1 job is not the next step. Textured-colour packages already
  use 75 vertices against an 81-vertex VU-memory ceiling and still need an
  XGKICK for each output packet.
- PATH3 and MFIFO remain gated: the earlier GIF wait was about 0.017 ms and the
  capture does not show producer-side DMA starvation.
