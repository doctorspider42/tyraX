# troubleshoot/tyra-docs.md

Documentation-rule failures. Symptom first.

## The editor build fails with a cmake error about `)TYRAXDOC"`

**Cause:** a `docs/*.md` page contains the raw-string delimiter `)TYRAXDOC"`
(`cmake/embed_docs.cmake` -> `docs_gen.hpp` embeds every page into the exe).
This is the only way the doc pages can break the build, so it is worth knowing.
**Fix:** remove the literal delimiter from the page.

## A new `docs/` page is not answered by the in-editor AI Assistant

**Cause:** the assistant's index is **derived from each page's own H1 and first
sentence**. A page that opens with a table, a quote or a bullet list is skipped,
and indexes as whatever prose comes next.
**Fix:** open the page with a plain prose sentence saying what the thing *is*.
Also list the new page in `docs/README.md` with its one-paragraph summary — a
page is not done until it is listed there.

## An installed project skill / `AGENTS.md` silently stopped refreshing

**Cause:** the "Generated by TyraX" ownership marker is searched in the **first
4 KB**, not 512 B. A skill's `description:` can run long, so a new skill whose
marker landed past byte 512 read as **user-owned** and stopped being rewritten —
with no error.
**Fix:** keep the marker inside the first 4 KB (see
`aisupport.cpp`, `docs/ai-support.md`), or add to the skip list deliberately.

## `.agents/skills/` has drifted from `.agents/skills/`

**Cause:** the twin was added as a one-off snapshot with no sync since, and had
drifted a full retired-`PROGRESS.md` behind — plus it pointed at a `.Codex/`
scripts path that exists in no checkout — before anyone noticed.
**Fix:** never hand-edit one side. Mirror any skill edit, any new skill and any
`troubleshoot/` folder in the **same commit**, with the two substitutions only:
the skills path itself, and `AGENTS.md` in place of the root instruction file.
`.agents/skills/` is the source of truth.

## A merge conflicts in a file everyone edits

**Cause:** a file is the single most reliable conflict hot spot in the repo.
`src/templates.cpp` (codegen rows) and `PROGRESS.md` (retired for exactly this
reason) are the historical examples.
**Fix:** for `templates.cpp`, prefer re-applying against the new base over
keeping your block; for a retired file, delete it and move the information into
the commit message and PR body. See `skills/tyra-pr/SKILL.md`.

## A documented screenshot shows something that no longer exists

**Cause:** `docs/img/*.png` is documentation and goes stale exactly like prose —
but nothing warns you; the page still builds and the figure quietly shows the
string you deleted.
**Fix:** retake on the **same fixture** the old shot used (copy the example out
of the tree first — `--refresh-gen` mutates a checked-in example), drive the
editor with `--ui-script "... shot x.png"`, then look at the image before
declaring done. See `skills/tyra-testing/SKILL.md`.
