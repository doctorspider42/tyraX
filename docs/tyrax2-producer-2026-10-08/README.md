# Producer attribution evidence

The [report](../tyrax2-producer-attribution.md) describes the protocol, accepted
results, caveats and proposed next intervention. This is attribution, not an
accepted renderer optimization.

- `emulator`: twenty complete phases, strict analysis, runtime log, visual smoke
  checks, launch authority, and host accounting/negative-input tests.
- `physical`: twenty complete phases, 11,770 rows, strict analysis, runtime logs,
  host input hashes, launch authority and the same host controls.
- `sources`: generators, analyzer, ledger tests, exact relevant private generated
  sources, build/source/native binding and instrumentation-site inventories.
- `evidence-sha256.json`: hashes of archive payload, excluding itself.

Accepted fixture: `F:/Projects/tyrax2-producer-20261008-v4`. Its ELF and game
assets remain outside the repository. Version 1 stopped at a commented-out
duplicate method during generation; version 2 stopped at a changed cull anchor.
Version 3 built and passed initial rotation accounting but was superseded because
runtime-hidden vehicle materials could still trigger reflection captures.
Neither earlier fixture supplies accepted performance results.

No actual-writer geometry oracle was newly added: this experiment changes
instrumentation and explicitly stated workload controls, not geometry algorithms.
Passing the ledger/pose checks and visual smoke checks does not prove pixel
identity. The emulator's timings are never physical PS2 performance evidence.
