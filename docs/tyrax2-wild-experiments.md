# Private unconventional rendering experiments

The [independent fifteen-idea review](tyrax2-wild-source-2026-10-05/history/fifteen-ideas-report.md)
proposes changes of representation and arithmetic for the night workload.
The agent received previous source/measurement evidence, without our pending
optimization ideas. These are hypotheses, not measured savings. Private trials
preserve the ordinary full night, presentation path and effect masks.

## Four frustum planes through VU0

Kind5 packs four plane rows once per beam-render call, then invokes the existing
external matrix-vector operation on VU0. The last two planes remain scalar.
Unsafe ranges and cancellation-sensitive boundaries use the original scalar
predicate. The same ELF switches Off/On/Off and On/Off/On; no new clock reads,
fences, waits or timed telemetry are introduced. Common branch/layout/observer
cost remains unpriced.

Host controls and native source/ABI/disassembly reviews passed. Both emulator
orders completed 10,800 loops with positive sparse scene activation and zero
reported mismatches. The forward raster observer started late and missed
phase0; its partial attempt is retained. All three reverse images were captured
with owned-process and actual-flag records and reviewed as qualitatively normal.
This does not establish pixel equality or physical television appearance.

The [both-order PS2 record](tyrax2-wild-2026-10-05.json) retains 10,800 completed
loops, 768 raw samples and 30 bounded chunks. In the forward run, inclusive
elapsed-minus-pacing means were 18.989370 / 19.086022 / 18.915335 ms: candidate
was 0.096651 / 0.170687 ms slower than its controls. In reverse they were
19.089426 / 19.082042 / 19.089383 ms: candidate was 0.007384 / 0.007341 ms
slower. Every phase retained approximately 33.367 ms engine presentation
periods. No performance gain or production promotion is accepted.

Each cold witness reached eight real sphere predicates, with positive candidate
action in On arms and zero comparison failures. The deterministic target
selfguard also runs outside the timed windows. These checks cover observed
inputs; they do not prove universal EE/VU0 precision or full-window activation
rates. The inclusive timing response includes existing routing/waits and cannot
be interpreted as a pure processor cost or added to earlier effect-removal gains.

## Squared cone predicate

Kind6 replaces one perpendicular square-root comparison with a guarded squared
comparison, retaining radius/order arithmetic and the legacy boundary fallback.
Host/original-function and native reviews passed. Its emulator completed 5,400
loops, but actual caster selection is unreachable in this frozen scene:
`FLASH_SHADOW_VOLUMES=0`, `FLASHLIGHT_USED=0` and
`SPOT_SHADOW_VOLUMES_USED=false`. All real counters are zero, and the target
selfguard is not reached. This is an inactive workload result, not a failed
performance optimization. No physical cone timing trial was run.

## Representation candidates still open

The ordinary corona path inherits lighting and precise clipping that the
existing billboard program cannot reproduce unconditionally. A blanket
descriptor conversion therefore remains at feasibility.

A pool's 96 source list vertices repeat its color. The later private
[Pool2 table experiment](tyrax2-pool2-colors.md) preserves package boundaries,
uses bank-local descriptors and qualifies both physical orders plus twelve
fixed-case emulator captures. Six decoded VU payload pairs match exactly, but
the small forward timing improvement does not repeat in reverse order.
Original EE expanded-color work remains; the candidate stays private.

The unique-grid proposal also has real remaining work: ordinary light pools use
96 list vertices, while height queries already use 25 cached grid points. With
the existing 75-vertex package limit, one pool splits into 75 + 21 vertices;
package-local unique records total 21 + 10, rather than one global 25-record
upload. Any experiment must preserve original output order and precise clipping.

## Preservation

The [source/control snapshot](tyrax2-wild-source-2026-10-05/README.md) contains
five unique postimages for the two candidates, exact parser/sampler controls,
native/config summaries and reconstruction pins. Each candidate changes four
of 497 frozenV3 inputs; 493 remain identical. Its historical boundary predates
physical completion and is retained unchanged. The separate
[physical payload manifest](tyrax2-wild-physical-2026-10-05/SHA256.json)
binds raw logs, normalization, strict calculations and independent reviews.
No ELF, asset or executable binary is embedded in these documentation packages.
