# Strict private kind8 lattice controls

This overlay parses the independent pool lattice dialect directly as kind8. It preserves the original quiet sampler, ABI, phase/chunk/raw clock accounting and all inherited strict ordinary-clock/display/profiling/record-completeness checks. It never converts kind8 records to kind7.

Authoritative CLI:

`python analyze-night-cli.py --stdout STDOUT --artifact ARTIFACT --environment ps2 --kind 8 --order 0 --joint 0 --restored 0 --report NEW_REPORT`

Use order1 for the reverse trial. Existing reports cannot be overwritten. The CLI hashes stdout, the authoritative file artifact and all parser modules into its report. Root separately binds native source, ELF, assets, launch freshness and process ownership; parser success cannot prove an actual new boot by itself.

Kind8 requires idea2 table flags1/1/1, lattice flags0/1/0 or1/0/1, selected/applied phase flags, no ordinary/extra/wild cuts, samplerOn in every phase, exact three phase rows, exact six cold rows at offsets750/1155 and complete5400-loop done/raw/chunk evidence. It requires positive eligible/applied lattice activation and a unique-count reduction in every On cold witness; Off must report no candidate preparation/application and identical source/unique counts. Incomplete, malformed, duplicated, unknown-field, wrong-ABI/clock/config/phase, nondecimal/overflow and incoherent counter captures reject.

`NIGHTLATTICEGATES` source/invocations include all generic cull fallbacks in this source revision; only eligible/applied identify qualifying pool packages. Source/unique counts are transform-count bookkeeping, not pure VU cycle savings. Cold activation does not establish continuous warm activation. The unchanged table counters are compatibility eligibility counters and do not describe the lattice writer's actual one-color VIF payload.

`proof.json` retains two authoritative CLI host positives and47 negative controls. `legacy-regression.json` retains all28 prior host dialect/order/optimization captures accepted unchanged. Host runtime inputs exercise actual kind8 headers over5400 synthetic loops/order; no target/device, SDK-byte, VU-output or physical performance claim follows. `analyze-loop.py` is byte-identical to the prior controls. Host tests and this parser do not modify the frozen prototype or native mirror.
