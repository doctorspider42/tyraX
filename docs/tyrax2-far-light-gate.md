# Conservative far-light rejection experiment

A private same-ELF experiment rejected clearly distant dynamic lights before
distance evaluation, preserving the original ordered light-selection algorithm.
Both physical orders made the full night slower, so this candidate is rejected
and is not part of the production engine.

The predicate classifies bounded float exponents with a large distance margin.
Unsupported values and lights near the range boundary retain the original
calculation. It preserves camera-light ordering, dynamic registry ordering,
skip-slot behavior, strict score ties and fallback identity. It introduces no
registry cache. The original square root already uses hardware `sqrt.s`.

## Physical result

| Order and applied flags | Control mean (ms) | Candidate mean (ms) | Candidate minus control (ms) |
|---|---:|---:|---:|
| Off / On / Off | 19.170683 | 19.409211 | +0.238528 |
| On / Off / On | 19.151399 | 19.381433 | +0.230035 |

Means are ordinary loop elapsed time minus existing pacing, retaining hardware
waits and preemption; they are not an isolated EE instruction bill. Each boot
completed 5400 loops, 384 raw samples and 15 chunks. Every adjacent contrast
also favors the old path. Repeated outer-arm spreads are 0.055085 and 0.101568
ms, smaller than the net regressions. Rendered flip-return periods remain about
33.367 ms in every arm. No full-quality 60 fps claim follows.

All effects, receiver policies and ordinary pool-table behavior remain the same.
The two configurations switch only the private predicate. Common compiled
branching, code layout and sampler apparatus remain in both arms and are not
separately priced. Sparse counters execute at offsets 750 and 1155, outside the
priced interval 800..1119; no new timed clocks, fences or GPU holds are added.

Each of twelve cold observations sees 114 selection calls and 912 candidates.
The fast scan rejects 61 candidates (6.69%); actual application is 61 in On and
zero in Off. A second untimed scan compares the returned light pointer against
the other algorithm: all 1368 physical comparisons agree. These observations
qualify activation and pointer parity at those frames, not continuous all-frame
equality or eliminated DMA submissions. Checking every candidate to save only
a small fraction of distance calculations is consistent with the measured
regression; the experiment does not isolate its precise instruction-level cause.

## Qualification and retained limits

The native build binds 501 frozen source inputs, linked ELF/symbol text, target
sampler layout, 298 assets and all sixteen resident microprogram images.
Only four engine/debug source files differ from the ordinary corona24 pricing
baseline; generated game code is unchanged. The ELF SHA-256 is
`9b8a7b5acc9562a43b4463119d10eeb9ecc3df70e37998fdd08611b882a7e148`.

Host controls compare two million selections and twenty million raw-bit gate
cases, with 345155 rejections and no host disagreement. Host math does not
prove all R5900 floating-point behavior. Ten malformed physical protocol
variants are rejected by replaying the strict analyzer against the completed
captures. The final physical boot leaves the candidate running without a reset.
No new TV visual confirmation or physical screenshot was obtained in this trial.

The emulator attempt failed before game boot because display :93 was absent;
its Qt startup output is preserved and excluded. It supplies no raster or
runtime qualification. Previous candidates' screenshots are not substituted.
The early release authority requested raster qualification before pricing;
that condition remains unmet. The physical elapsed contrasts are retained as
diagnostic rejection evidence, not an appearance-qualified promotion result.
The candidate is rejected on physical performance, so no production promotion
or extra emulator replay is required to claim the measured regression.

The [source/evidence checkpoint](tyrax2-far-light-gate-2026-10-05/README.md)
preserves both physical orders, four exact source postimages, manifests,
qualification records, host controls and the excluded emulator startup.
The [EE audit](tyrax2-ee-performance-audit-2026-10-05.md) identifies broader
producer work to investigate next; broadening this predicate is not the first
recommended experiment.
