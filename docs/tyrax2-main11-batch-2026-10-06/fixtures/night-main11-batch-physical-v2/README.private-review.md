This is an unfrozen candidate source fixture. No native build, emulator, console run, positive activation, fps gain, output equivalence or release is established by its creation. Root owns those stages. Do not overwrite an existing target-source-manifest.json or reuse a published authority.

## Ownership and admission

Both arms initially prepare the normal original individual world-space GeoPart carriers at the pre-secondary-view seam. Private groups concatenate their initialized position and color arrays, with their own BagArray ownership, stamps, precise bounds and info descriptors. No generic static-builder rebake, alternative GI staging or inactive ST copy is used. All selected actual bags must be untextured, opaque alpha128, no shader lighting, billboard, strip, env/AO/emission companion, moving/local-space representation, custom VU, BLSS proxy mode or altered depth/blend contract. Full info fields and identity model must agree.

Prepared merged arrays are never resized, rebuilt or freed within the scene. At the pre-secondary seam, any dirty or content/bbox stamp change permanently demotes the affected group without clearing dirty. Later original reflection/main consumers retain their original dirty handling. Scene generation resets private groups together with existing scene lifecycle; native lifetime qualification is still required. Initial common carrier preparation clears initial dirty before the shared reflection-content key, unlike untouched production. Both arms share this setup, but initial production key/cadence equivalence is **not** claimed. Setup and common descriptor/key footprint are unpriced by the eventual runtime contrast.

Replacement occurs only at the existing main per-part call. Every original object-loop operation and heavy drip still executes. A group requires its first contiguous member to reach that call, all members active/visible and passing original coarse/occlusion tests, no projected object probe mode, and the original heavy queue completely drained. With no pending heavy work and no other object between the run members, concatenation preserves this run's triangle order. A refused first visit locks the whole run to originals for that view; later members cannot retroactively replace an already drawn earlier member.

Every original member bound and the merged bound must be fully inside the current frustum. The first qualifying view uses a private source-identical copy of production invertAffine/buildSpotForBag and the existing stapipSpotHasNoInfluence function. Member/group sphere picks must select the same light and have the same effective enabled/filter outcome. The complete exact semantic light state (count/all active scene lights/global fallback), VP/frustum, info/model, fog and carrier stamps is retained. A later key change permanently demotes the group. No hash is used for admission equality. Subsequent views compare the key using a scratch vector reserved during setup. Unchanged admitted keys avoid repeating the expensive light picks; common key/culling work remains paid on both arms. This is deliberately a restricted stationary fixture, not a generic batching API.

## Cold evidence protocol

Kind29 is full night for all phases, table enabled, sampler1; candidate On/Off/On or reverse. ProducerTiming is always false and inherited NIGHTPROD fields are zero. No new Count reads or waits were added. Cold750/1155 reset before the loop and emit after endLoop, outside priced windows.

Each cold frame emits one NIGHTMAINBATCH, three NIGHTMAINBATCHGROUP and eleven NIGHTMAINBATCHMEMBER rows, all unsigned decimal. draft-review.json lists exact fields. Group/member rows bind ordinal, resolved object, stable ID, run, original/copied counts and initialized semantic position/color hashes. The oracle also compares all four position words and four color words for each vertex; no inactive ST fields or structure padding is read. Retired resized carriers are bounded by their actual counts; a stale retired copy can be explicitly reported in a mutation qualification rather than dereferenced past its array.

Actual Core post-main-frustum producer acceptance populates candidate/main original/grouped counters. ReflectionUses uses the same accepted hook for the two original reflected-object submit loops. Eligibility/admitted fields describe guarded requests, separate from accepted submitted fields. Group count is vertex count; members is4/4/3; first is ordinal0/4/8. geometryCompared and verticesCompared count vertex elements; colorBytesCompared is16 times those elements. FNV hashes witness initialized inputs and membership; they do not prove packet, shader, clip or final raster equivalence.

A complete valid fallback-only run is a diagnostic result with no candidate pricing activation. Positive accepted replacement plus independent semantic/output/lifetime qualification is required before attributing a timing contrast to useful batching. No expected3group activation or eleven skipped main bags is inferred from the authoring inventory.
