This private experiment evaluates a guarded conversion of typed corona triangle pairs into GS SPRITE endpoints after the original six vertices have completed the TC transform, fog and lighting path. It is not an accepted optimization for the qualified ordinary scene.

## Scope and source provenance

The comparison starts at qualified pool2 EE baseline V2 (499 source files) and ends at corona pricing V6 / physical V2 (500 files). The exact 14-file source list and before/after hashes are in `source-postimages.json`; 486 files are unchanged. The source archive preserves exact textual bytes and the patch is for review, not automatic installation. Generated game source changes require a separate code-generator decision before any product promotion.

The candidate is default Off. A typed owner binds the exact vertex, ST and color streams and their count. Cold admission requires direct whole-quad slices, the TC path, full precise clipping, no strip/table slice/billboard/texture override and the currently supported depth domain. Crossing package boundaries fall back. The candidate retains original fog, lighting, blending, depth testing and batch order; it does not force every package to 72 vertices. Its post-transform predicate compares all six final packed RGBA, Z/F and bounded Q plus rectangle/ST/ADC conditions before compaction. The two-endpoint reduction saves GS input for accepted packages; it does not avoid the original six EE/VU input transformations.

## Native evidence and limits

The V5 kernel assembled as TC512, but the complete VU1Clip resident family including both billboards was 2046 instructions against a 2042 limit. Root rejected it before launch. V6 removed redundant lower operations without removing predicates, classes or effects. Actual TC506 fits the full families at 2040 VU1Clip / 1840 EEClip. All 17 wrappers, other VU images, target ABI (CoronaCounter36), and 298 assets including four ADPCM files remain separately audited. A successful assembly and image identity are not proof of VU path semantics or pixel output.

## Current applicability rejection

The actual diagnostic V1 used the ordinary Hybrid renderer depth: 24 depth bits, scale 8388607.5. The EE admission predicate explicitly requires `RendererCoreDepth::bits == 16`, so the candidate input marker was absent. READY alone therefore did not qualify the candidate. Root archived and stopped the rejected arm1 run; arm0 raster was pure black. Neither capture supports SPRITE acceptance or raster equivalence. Do not reinterpret this as an activated slow/fast comparison.

The ordinary kind9 order0 run kept Hybrid and all authored effects. Root reports 5400 loops completed and six cold gates, each with cold1/source12/eligible0/requested0/fallback1, fogOn1/shaderLit1/invalid0, with context depth2 (Hybrid). Its raw capture was retained and the owned instance stopped. The initial strict V1 parser rejected timestamp prefixes; the additional read-only V2 reanalysis authority now records kind9/order0, 5400 loops, 384 raw rows and 15 chunks, with coronaColdRequests0 and actualSpriteOutputAcceptedfalse. The old rejected authority is preserved unchanged. These are root-reported checkpoint facts, not a finalized analyzer result. No SPRITE pricing is allowed on the evidence currently available. Zero requests can establish inapplicability at this gate; positive EE requests still cannot establish VU acceptance. The strict kind9 analyzer keeps kind9 identity, full-night masks zero, table On in every phase, full sampling requirements and typed request-counter partitioning. It reports actual output unknown, never promotes requests into accepted sprites.

## Future 24-bit proof obligation

The current equality proof for ITOF0 followed by float subtraction is restricted to positive packed Z integers 0..0xffff0 (20 bits) and final finite bounded Q. Ordinary 24-bit depth combined with FTOI4 packing has a nominal packed-Z domain extending toward 28 bits; ITOF0 is not injective over arbitrary integers of that width. The 20-bit host proof therefore cannot justify simply deleting the EE depth guard.

This is not a proof that every actually reachable 24-bit FTOI4 output loses information. Reachable values derive from the original target floating-point conversion and can have a magnitude-dependent spacing; their exact integer-to-float round trip needs a separate proof using actual target conversion, range, packing and clip semantics. Another exact comparison could be considered only with a demonstrated instruction/representation contract and a complete resident-budget audit. No silent depth-format change, float-epsilon equality, low16-only Z test, quality cut or class eviction is acceptable.

## Final experiment decision

UNPROMOTED. No further candidate repair or SPRITE pricing is authorized in this experiment. Ordinary Hybrid24 is inapplicable to the current16 gate. Capability Bits16 reached the request marker but emitted unchanged TRIANGLE72, so this is a runtime false negative. All12 quads in both arms passed the completed-output predicate; the whole72-vertex payloads are byte-identical SHA a7d5bcc19449411972cb02329c5a98b77fc6155b64103f2366bca2c2588c6546. The sealed oracle identifies six next-issued-word FMAND reads after upper SUB. Pinned PCSX2 exposes arithmetic MAC flags at four cycles and does not provide an implicit VF dependency stall for FMAND. This is a concrete mechanism inferred from actual native scheduling and pinned semantics; no target instruction trace proved the first taken branch. The native total2040 leaves two spare instructions; a naive three-word delay at six sites would exceed budget. No quality cuts, depth-format change or class eviction are proposed.

The experiment is closed without promotion. No gain claim, accepted target SPRITE output, full-night output equivalence or product readiness. Ordinary V2 parser reanalysis is retained alongside its original V1 rejection. V2 capability diagnostics explicitly use Bits16 and remain separate from ordinary Hybrid night. Their case1 Off reached READY but had a black raster; On contained marker0x8848 yet retained completed TRIANGLE72, so the decoder rejected it. The exact owned On process32017 was archived and stopped. Root observed the first actual quad satisfying valid_quad in both arms (packedZ5240/F3060, bounded Q approximately0.05, RGBA32/65/98/128, endpoint orientation5/1). This first-quad observation does not prove acceptance of the whole package or correctness of the scheduled predicate. The sealed oracle diagnosis is preserved; its scheduling mechanism is inferred rather than instruction-traced. Actual sprites and pixel equivalence remain unproved. Source archives contain text and hash proofs; native binaries, resources, images and savestates are hash references only.
