sampler Off/On/Off, eleven-box Full/Hidden/Full, one-arm vehicle motion and
one-arm showcase portal route. Each completes 5400 loops. The portal cold
witnesses establish two successful crossings through each portal. Root reviewed

the quiet-window review.

`inventory.json` identifies copied files and hash-only native inputs.
`run-list.root-final.json` is the selected manifest whose hash it records.
Binary/SDK/asset/source-tree closure is retained through existing provenance
records rather than copied wholesale. The archive is evidence, not a portable
game project or build dependency bundle. Scripts retain original laboratory
paths; use explicit paths when replaying parsers on the archived captures.

PCSX2 configuration files are **post-run** bytes differing from their launch
hashes. Exact original INI bytes are not asserted. Sample configurations are
explicit reconstructions checked against their startup hash. Raw logs and
samples retain their original bytes; Git normalization is disabled here.

The rejected PS2 start never reached loadelf or a game-start marker. Additional
original client stdout/stderr and their hashes are in `hardware-supplement.json`.
No physical price, observer correction, TV latency or stable-night-60 result is
accepted by this archive. Initial telemetry-contaminated v3 runs are excluded
from this quiet evidence set and remain in the laboratory as protocol-only runs.
