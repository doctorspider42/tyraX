# Overnight wild rendering experiments — 2026-10-05 (publication draft)

These private experiments test specific implementation alternatives while retaining the ordinary night scene and presentation path. They are diagnostics, not shipping optimizations. The independent fifteen-idea report is preserved with its source review; confidence labels describe proposed mechanisms and risks, not measured gains. No timing results are accepted in this draft.

The first corona representation proposal was held at feasibility. The ordinary corona batch inherits lighting and precise clipping that the existing billboard shader cannot reproduce unconditionally. Full-batch light selection, boundary clipping, transform rounding and fog also require proof. No blanket unlit conversion or quality reduction was made, and no corona candidate was integrated.

Two smaller experiments use the frozen nightV3 production-derived fixture, without the SPR/CALL or pool-color-cache prototypes. Both keep ordinary/extra effect masks zero, retain all effects and use the same existing sampler in all three phases. Config `5 order 0 0` selects the plane predicate; `6 order 0 0` selects the separate cone predicate. Order0 is Off/On/Off and order1 On/Off/On. Each candidate has its own source/native identity. Common protocol support for both variants does not establish activation of both candidates in either fixture.

The plane experiment packs the first four frustum planes into a matrix once per beam-render invocation and calls the existing external VU0 matrix-vector operator. The last two tests remain scalar. Numeric range and cancellation-aware near-boundary guards return to the exact original scalar loop. CandidateOff retains that original loop. Camera pull, tint, culling inputs, retained geometry, batch ordering and submission remain unchanged outside this local predicate and its preparation. Actual native disassembly confirms the external call and VU0 load/MAC/store instructions; it establishes implementation presence, not arithmetic equivalence or speed.

The cone experiment is a guarded scalar squared predicate with legacy fallback and cold ID/order/T-bit comparisons. The current fixture cannot reach its intended caster selection: FLASH_SHADOW_VOLUMES=0, FLASHLIGHT_USED=0 and SPOT_SHADOW_VOLUMES_USED=false. Its completed emulator run therefore validates protocol/source linkage only and reports an inactive candidate. It is not a negative performance result. No physical cone trial was run or claimed.

The shared observer writes candidate counters only on existing untimed offsets750/1155. Exact phase/variant/application records, real invocation eligibility, fallback, input/output units and mismatch/overflow state are checked by the strict parser. Deterministic target self-tests are excluded from real activation counts. There are no additional Count reads, fences, waits, forced timesteps or timed telemetry. This preserves the existing sampler seams; it does not price common branches, code/layout or descriptor footprint as zero.

Host controls passed both arm orders and old/new protocol kinds. Separate host math/original-function oracles disclose that binary32/FMA shims do not prove R5900/VU0 behavior. Native reviews bind497 source inputs,488 mirrored inputs plus9 ancillary files, actual dependencies/objects/link, target ABI,298 runtime assets and matching stripped/symbol `.text`.
