7.2. Performance Counter Operation Details 
7.2.1. Counter Increment 
Counters PCR0 and PCR1 increment by 1 whenever the events specified in PCCR.EVENT0 and 
PCCR.EVENT1 are generated.  However, the following three conditions must be met: 
1. Counter enable flag PCCR.CTE is set to 1. 
2. The processor’s operation mode  matches the operation mode specified in PCCR.U0 / PCCR.S0 / 
PCCR.K0 / PCCR.EXL0 or PCCR.U1 / PCCR.S1 / PCCR.K1 / PCCR.EXL1. 
3. Level 2 exception handlers  are not being executed.
