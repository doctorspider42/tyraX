# vu0-bench

An A/B bench for the engine's VU0 macro-mode math (`Vec4`, `M4x4`): per
operator, a bit-exact hash of the results (xyz and w separately) and the COP0
cycles per call, printed to `bin/log.txt` as `VU0BENCH <op> xyz=... w=... cyc/op=...`.
Results and the first numbers: [docs/vu0-macro-mode.md](../../docs/vu0-macro-mode.md).

## Running it

1. `tyrax-editor --new vu0-bench <short dir> 20 20 empty --no-terrain`
2. Copy `vu0_bench.cpp` into the project's `src/`.
3. In `src/terrain_game.cpp`, delete the first (`// Generated by TyraX`) line to
   own the file, declare `void vu0BenchRun();` after the includes and call it at
   the end of `TerrainGame::init()`.
4. `tyrax-editor --build <dir> --run` (or `--run-ps2 <ip>` - console cycles are
   the honest ones; PCSX2's are only good for ratios), then read `bin/log.txt`
   (or the `[ps2]` lines) until `VU0BENCH done`.

For an A/B, build a second copy of the project against the other engine and
diff the two logs: the `xyz=` hashes must match line for line.

## `vu0_kernels_bench.cpp`

Prototype kernels against the engine's scalar code in the SAME ELF, so no
second build is needed: `mmi::equal64` against `memcmp` (correctness over every
single-bit difference, cycles per call), and the VU0 structure-of-arrays
`frustumCheckAABB` prototype against a verbatim copy of the scalar function
(an oracle over 163 840 randomized and plane-touching boxes, then cycles). Add
it beside `vu0_bench.cpp`, declare `void vu0KernelsBenchRun();` and call it after
`vu0BenchRun()`; it prints `KBENCH ...` lines and `KBENCH done`.
